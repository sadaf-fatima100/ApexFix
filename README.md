# ApexFix - Premium Appliance Repair & Maintenance

ApexFix is a modern, high-conversion, responsive web application for luxury home appliance repair and maintenance services across Dubai and the UAE.

## Features

- **Hero & Precision Branding**: Custom SVG motion paths, speed trails, and dynamic repair typography.
- **Floating Sticky Navbar**: Frosted glassmorphism blur backdrop with automatic section active link detection (Scroll Spy).
- **Service Categories**: Comprehensive diagnostic and repair flows for Refrigerators, Washing Machines, Dryers, Dishwashers, Ovens, and Central AC/HVAC systems.
- **Brand Showcase**: Multi-brand filtering system across 20+ top international brands (Samsung, Bosch, Siemens, LG, Daikin, Miele, etc.) with continuous border animation.
- **Interactive Dubai Dispatch Hub**: Service coverage map across major districts in Dubai & UAE.
- **Interactive FAQ Accordion**: Smooth CSS grid height transitions with ApexFix Navy Blue brand buttons and WhatsApp discovery callout card.
- **Full Dark / Light Theme System**: Instant theme switching with persistent local storage preferences.
- **Mobile-First Responsive Engineering**: Optimized touch targets, iOS safe-area compliance, and smooth fluid layouts across all viewport sizes.

## Tech Stack

- **HTML5**: Semantic, accessible markup (ARIA attributes, SVG defs & clip paths)
- **CSS3**: Custom design tokens, glassmorphism, responsive grid & flexbox, hardware-accelerated transitions
- **Vanilla JavaScript**: Zero dependencies, lightweight event listeners, modal booking workflow, and scroll observers
